# mcd-deal-hunter

麦当劳点餐的省钱助手：**算清券用完到底花多少钱，以及怎么点更划算。**

一份真实对照（同一家店、同一份「麦辣鸡腿汉堡 + 中薯条」）：

| | 到店自取 | 外送到家 |
|---|---|---|
| 商品 | 36.50 | 40.50 |
| 配送费 | — | 6.00 |
| 打包费 | — | 1.90 |
| **合计** | **36.50** | **48.40** |

外送贵 **11.90 元（+33%）**。但差价的构成才是重点：

- **4.00 元是商品本身就贵了** —— 按订单金额比例走，约 11%，**凑单也摊不掉**
- **7.90 元是配送费 + 打包费** —— 固定金额，单越大摊得越薄

所以「外送永远比自取贵，凑单只能接近、到不了」。只看配送费会低估一半的真实差价 —— 这是本项目的出发点。

## 目标用户

- 经常点麦当劳、但不知道手里哪张券能在本店本单用的人
- 想省钱又懒得自己比价的人
- 在「外送还是自取」之间反复纠结的人
- 使用 DeepSeek Harness 等支持 Skill 的 AI 客户端，希望点餐决策有依据、而不是拍脑袋的人

## 它能回答什么

- 我有哪些券能用？
- 这单能省多少？
- 外送和自取，哪个划算、贵多少？
- 再凑一点能减吗，值不值？

## 安装

### 前置：配置麦当劳 MCP

先到 [麦当劳 MCP 开放平台](https://open.mcd.cn/mcp) 用手机号登录并申请 MCP Token。

然后在 DSH 的 profile 补丁文件里加入这段（**把 `YOUR_MCP_TOKEN` 换成你自己的 Token**）：

```yaml
- insert:
    - id: mcp-mcd
      name: "@deepseek-ai/dsh-mcp-client"
      config:
        serverName: mcd
        transport: streamable-http
        url: https://mcp.mcd.cn
        headers:
          Authorization: "Bearer YOUR_MCP_TOKEN"
```

保存后自动生效，不需要重启。配置好后模型会看到一批 `mcp__mcd__*` 工具。

### 安装本 Skill

把仓库放进 DSH 的 skills 目录：

```
~/.dsh/skills/mcd-deal-hunter/
├── SKILL.md
└── references/
```

放好后自动加载，下一轮对话即可使用。改 `SKILL.md` 保存即热更新。

## 使用示例

### 什么时候用

直接用自然语言问，不需要点名：

```
我想吃麦辣鸡腿堡，有什么券能用
这单能省多少
外送还是自取划算
有什么免费券，值不值得吃
```

### 问「这单多少钱」

> 龙焰鸡腿堡两件套，到店自取：**券后 20.48 元**，券 10 月 30 日到期。
>
> 前提：这个套餐只能靠券买，单点不卖，所以没有「另一种买法」可以跟它比。
>
> 菜单里龙焰鸡腿堡单品 15.9 元、三件套 26.9 元。20.48 值不值，取决于你想吃多少。

### 问「外送还是自取」

> 同一份餐：自取 **36.50 元**，外送 **48.40 元** —— 外送贵 **11.90 元（+33%）**。
>
> 差价构成
> - 商品加价 4.00 元 —— 按订单金额比例走，凑单摊不掉
> - 固定费用 7.90 元 —— 配送 + 打包，单越大摊得越薄
>
> **结论：自取划算。**

它不会只扔给你一个价格。外送贵在哪里、能不能靠凑单省回来、券会不会改变结论 —— 都会拆开说。

## 它不做什么

| 不做 | 原因 |
|---|---|
| 下单、付钱 | 它付不了款，最后一步永远是交给你自己按 |
| 重试下单 | 重试可能变成两单、扣两次钱 |
| 拿划线价当省钱基准 | 「比标价便宜」不等于最划算。没有真实可买的替代方案，就不说「省了多少钱」 |
| 编造优惠 | 本店没券就说没券，不会为了好看凑一个数字 |
| 讲内部过程 | 你不需要知道它查了几次，只需要知道多少钱 |
